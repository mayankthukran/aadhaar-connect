# Aadhaar System

A web-based Aadhaar authentication platform that allows users to register and verify their identity through a simulated Aadhaar database. This project demonstrates how identity systems can be digitized in a secure, accessible, and user-friendly manner.

## 🚀 Key Features

### User Portal

- 🔐 **Secure Registration & Login**: Users can register and log in with Aadhaar number validation and basic authentication.
- 📄 **Profile Dashboard**: View and edit personal details in a simulated profile with live form validation.
- 📝 **Profile Editing**: Inline edit mode for personal information, allowing updates to name, address, and contact details.
- 🌳 **Family Tree Visualization**: Interactive family tree component displaying relations and supporting modal dialogs to add new family members.
- 📱 **Responsive Design**: Mobile-friendly navigation menu with a collapsible hamburger menu and adaptive layout.

### Admin Portal

- 🛡️ **Pending Verifications**: Admin view with a list of pending Aadhaar verification requests and action buttons to approve or reject.
- 📊 **Reports & Analytics**: Data visualization component displaying aggregated statistics and charts for system usage and verifications.
- 📋 **Tab Navigation**: Easy switching between pending verifications and analytics sections.
- 🔄 **Real-time Actions**: Trigger and handle admin actions (approve/reject) with callback handlers.
- 📱 **Responsive Interface**: Collapsible mobile menu, dynamic header showing admin name and ID, and consistent layout across devices.

### Common Features

- 🌐 **Single Page Application (SPA)**: Built with React.js for fast client-side routing and component-based architecture.
- 💅 **UX & Styling**: Tailwind CSS for utility-first styling and Lucide React icons for intuitive UI elements.
- 🚀 **Deployment**: Hosted on Vercel for global availability.
- 🔄 **State Management**: React `useState` hooks manage view state and UI interactions.
- 🔒 **Simulated Backend**: Placeholder data flows represent backend integration points for future API connection.

## 📑 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/mayankthukran/aadhaar-connect.git
   ```
2. Navigate to the project directory:
   ```bash
   cd aadhaar-connect
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the application:
   ```bash
   npm start
   ```
